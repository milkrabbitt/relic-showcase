# 产品与用户流程
Relic 是“基于用户资料生成的 AI 角色”。用户决定使用哪些授权素材、如何确认人物，以及记住什么；角色不是被描述的真人本人。

1. 创建基本资料，保存服务端草稿。
2. 从手机文件导入 TXT / CSV / JSON、粘贴补充，或通过独立的电脑扫码授权上传。
3. 查看解析和预览，选择目标/自己说话人，不自动蒸馏。
4. 确认昵称、关系、表达、性格、生日/出生资料等；未知项允许空缺。
5. 明确同意将授权文字与人物资料交给 MiniMax，查看真实处理结果。
6. 聊天、多气泡与记忆修正，失败查询原请求并重试。

当前候选代码实现统一的深色首页、角色详情、分步创建、素材、画像、聊天、记忆和设置。免费试聊按角色200次，成功逻辑回复计一次，多气泡不重复扣。没有真实付费或系统推送扩项。

电脑上传授权、Apple/小程序身份关联与微信机器人连接是不同流程。机器人当前未通过新的真实收发验收；App自身创建和聊天不要求安装其他提取软件。
当前生产与真机缺口见[进度](progress.md)，页面实现不等于全部流程已交付。
