# 产品与用户流程

Relic让用户从自己获授权的素材创建可交流的AI角色。资料与角色并不等同于真实自然人，也不承诺复刻本人。

两种导入入口服务不同场景：手机文件/粘贴适合手头已有文本；电脑配对上传适合较大的文件。两者进入同一素材草稿流程，不导入后自动调用模型。用户先预览记录、选择目标说话人并确认资料；异常文件应给出可操作错误，重试不能重复生成素材。

现有实现覆盖TXT/CSV/JSON、人物资料、画像提取、聊天多气泡、手工与自动记忆、未读/已读、每角色200次试聊、独立机器人授权和删除入口。具体哪些已验见validation，不能据代码清单当作全部可用。

App与小程序可独立使用。用户主动验证并绑定身份后，新明确共享的角色使用统一后端。原有两端数据和余额保留各自归属，绑定不会自动合并。系统通知、付费和正式平台发布暂缓。
